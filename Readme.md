# 🎮 Family Game Tracker

En full-stack webbapp för familjens spelmatcher – tennis, schack, Monopol och mer!

## 🌐 Live Demo
[Klicka här](https://DITT-NAMN.github.io/FamilyGameTracker/)

## Tech Stack
- Frontend: Blazor WebAssembly
- Backend: ASP.NET Core Web API (.NET 8)
- Databas: SQL Server / LocalDB
- ORM: Entity Framework Core
- Tester: xUnit + NSubstitute
- CI/CD: GitHub Actions → GitHub Pages

## Kör lokalt
dotnet run (i FamilyGames.API)
dotnet run (i FamilyGames.Client)
dotnet test (för tester)
